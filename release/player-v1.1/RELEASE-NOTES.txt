STARFALL SALVAGE 1.1 - RELEASE NOTES
Player-package draft prepared 2026-10-14

THE GAME
- Story: 18 missions, six zones, 72 large scrolling rooms.
- Salvage, ordered relays, repair, physical crew escorts and guardians.
- Four pulse rigs, middle-route order choices and optional caches.
- Arcade: repeating 12-map route, changing hazard pressure, replacement
  pulse rigs and the choice to continue or bank an earned haul.

VERSION 1.1 CONTROLS
Retry, route order, workbench upgrades and Arcade banking now use explicit
highlighted choices: Up/Down selects and A confirms. B goes back or cancels
instead of silently choosing a different action after each round. Flight
physics and objective rules are unchanged by this controls update.

WHAT WAS VERIFIED
The exact native ROM in this download completed a fresh Story playthrough
in PyBoy 2.7.0: all 18 missions, 72 rooms, 18 guardians, seven crew rescues,
all four rigs and both middle-route orders. Pause froze gameplay, and
Title -> Continue restored the completed ending. No game-code change was
needed during the full campaign verification.

A separate focused regression covered the complete 12-map Arcade cycle
plus sector 13, banking 25,500, menu choices, retry/exit behavior and key
Story/Arcade save transitions. It did not test every possible route and
upgrade combination or indefinite Arcade loops.

The guided native campaign clear displayed 00:35:27, Rank B. CLEAR TIME
counts successful-room gameplay; it excludes menus, pauses and failed
attempts. This is a functional test measurement, not elapsed session time
or a measured first-time human completion time. Arcade has no fixed ending.

A separately identified official browser export completed all 18 missions,
72 rooms, 18 guardians and seven escorts in Codex's in-app browser. The
ending displayed STARFALL SAVED, CLEAR TIME 00:42:41, RANK B - GOT HOME.
This guided run used ordinary controls and frequent observation pauses.
It included failed attempts and retries; one visible Saved states recovery
returned to an already-earned mission 3 completion after an accidental
relaunch. No new progress was injected and no game-code change was needed.
The browser clear used the standard pulse initially and Wide Coil later,
including both middle-route orders. It does not add an all-four-rig or
complete Arcade browser test. Its timer has the same successful-room scope
as the native timer; 42:41 is not elapsed session or human first-play time.

WHAT REMAINS UNVERIFIED
- Physical Chromatic/other handheld and exact cartridge combinations.
- Native save persistence after emulator shutdown or handheld power-off.
- Speaker/headphone listening and music/sound-effect balance.
- Full browser-process termination, storage eviction, cross-origin save
  behavior and the final public browser host.
- First-time human completion time, enjoyment and difficulty balance.

The browser campaign result applies to the exact export and local in-app
browser identified above. The browser edition is not included in this
native download. SameBoy is a documented installation example, not a
tested emulator for this release.
